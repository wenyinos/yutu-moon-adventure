# 玉兔奔月｜月宫大冒险 🌕🐇

一款为**小红书小工具平台**打造的中秋主题竖屏跑酷小游戏。

> **60 秒，看你能不能跑到月亮上。**
> 打开即玩 → 单指操作 → 60 秒挑战 → 获得中秋称号 → 生成结果卡片 → 保存/发布到小红书

- 仓库：<https://github.com/wenyinos/yutu-moon-adventure>
- 作者：Wenyin Root
- 版本：V2.0（含 V1.0 MVP 与 V2.0 全部玩法扩展）

---

## 玩法

| 操作 | 说明 |
|---|---|
| 点击屏幕 | 玉兔跳跃（松手可截断上升，实现小跳/大跳） |
| 自动奔跑 | 无需控制方向，专注节奏 |
| ♥♥♥ | 3 点生命，碰撞扣 1 点并中断连击，归零提前结束 |

60 秒内穿越 **桂花林 → 云海 → 月宫 → 满月** 四个阶段：速度与障碍密度递增，月相从月牙渐变为满月。收集 **月饼 / 桂花 / 星星 / 月光球** 得分，连击 ×5 触发**月华加成**（收集分 ×2），×10 触发**满月冲刺**（无敌加速）。跑完生成 9:16 中秋结果卡，一键保存相册或发布笔记。

## 特性一览

**V1.0 核心**

- Canvas 2D 游戏循环，60fps，双层画布（背景层 + 游戏层）
- 可变跳跃高度、AABB 宽容碰撞、对象池粒子、DPR 自适应（上限 2x）
- 连击系统、月相系统、5 种结局称号、Canvas 分享卡（4 种模板可切换）
- `saveImageToPhotosAlbum` / `writeTempFile` / `postNote` 全接入，带能力检测与浏览器环境降级
- localStorage 保存最高分 / 累计收集 / 称号

**V2.0 扩展**

- 冒险模式：桂花林 → 云海 → 月宫长廊 → 广寒宫 → 月桂神树，5 关通关解锁
- 4 套玉兔皮肤（桂花兔桂花 ×1.5、金玉兔收集 ×1.2、月神兔增益时长 ×1.5）
- 4 个技能：二段跳（被动）、月光护盾 / 月影冲刺 / 桂花祝福（充能制主动技）
- 10 个成就、本机排行榜（前 5）、种子化每日挑战（同一天关卡固定，完全离线）
- 节日彩蛋：偶遇嫦娥、吴刚路过、满月烟花、月中玉影（5% 概率）

## 技术方案

**零资源文件**：所有视觉元素（玉兔、道具、障碍、场景剪影、月相）由 Canvas 程序化绘制并离屏缓存；全部音效与五声音阶 BGM 由 Web Audio API 实时合成（前视调度音序器）。包体约 172KB，无版权风险。

**平台合规**（依据小红书《小工具容器·能力清单》）：

- 纯本地 HTML/CSS/JS，无网络请求、无 CDN、无 Worker/WASM/iframe
- JavaScript 全部外置 `.js`，无行内事件，全部 `addEventListener`
- 语法严格限定 ES2017 子集（兼容 Android 8.1 / Chrome 61 基线），无 `?.`、`??`、`Array.flat` 等
- 端 API 均做 `window.xhs && window.xhs.miniTool` 能力检测，不可用时游戏照常运行

> ⚠️ 正式上传小红书前，须以小工具上传页当前提供的"改写口令"及对应版本 `SKILL.md` 为最终校验与打包依据。

## 目录结构

```text
yutu-moon-adventure/
├── index.html          # 页面骨架（主页/游戏/结果/地图/小屋/成就/排行/关于）
├── css/
│   └── style.css       # 全局样式（夜空国风主题）
├── js/
│   ├── app.js          # 启动入口 + rAF 主循环
│   ├── game.js         # 状态机、事件生成、碰撞、彩蛋、HUD
│   ├── render.js       # 双层渲染（天空/月相/视差/地面/世界）
│   ├── sprites.js      # 程序化美术（玉兔/道具/障碍/剪影/月相）
│   ├── player.js       # 玩家物理（跳跃/重力/碰撞盒）
│   ├── obstacle.js     # 障碍管理
│   ├── item.js         # 收集物（直线/弧线串、磁吸）
│   ├── particles.js    # 粒子特效（星屑/尘土/拖尾/烟花/桂花雨）
│   ├── score.js        # 计分、连击、称号判定
│   ├── audio.js        # Web Audio 合成音效与 BGM
│   ├── storage.js      # localStorage 存档
│   ├── result.js       # 结算与分享卡
│   ├── xhs.js          # 小红书端能力适配（检测/降级）
│   ├── ui.js           # 屏幕切换与各页面渲染
│   ├── achievements.js # 成就（V2）
│   ├── skins.js        # 皮肤（V2）
│   ├── skills.js       # 技能与局内技能条（V2）
│   ├── daily.js        # 种子化每日挑战（V2）
│   └── util.js         # 工具函数（LCG 种子随机、对象池等）
└── data/
    └── game.js         # 全部数值配置（分数/称号/成就/皮肤/技能/关卡）
```

> 配置用 `data/game.js` 而非 JSON：小工具容器禁用 `fetch`，本地 JSON 无法读取，故以 JS 全局变量注入。调数值平衡只需改这一个文件。

## 本地运行

无任何构建依赖，静态服务即可：

```bash
python3 -m http.server 8765
# 打开 http://127.0.0.1:8765
```

浏览器 DevTools 切换移动端视口（375×812 等）体验最佳。`window.xhs` 不存在时自动进入浏览器降级模式（保存图片走下载，发布按钮给出提示）。
